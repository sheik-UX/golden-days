GOLDEN DAYS BRAND FONTS DIRECTORY
==================================

Drop the official brand font files here:

1. Oskar Two (Headings):
   - OskarTwo.woff2
   - OskarTwo-Bold.woff2

2. Firula (Script / Supporting):
   - Firula.woff2

The CSS in index.html is configured to automatically load these font files via @font-face:
- font-family: "Oskar Two"; src: url("fonts/OskarTwo.woff2") format("woff2");
- font-family: "Firula"; src: url("fonts/Firula.woff2") format("woff2");

Until these commercial font files are provided by Blake/Client, the website uses clean, premium geometric sans-serif fallbacks (League Spartan + Nunito Sans) without any Arial fallbacks.
